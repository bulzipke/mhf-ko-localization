# 검수 보고서 양식

검수자와 수정자가 같은 CSV 버전을 기준으로 이야기하기 위한 양식이다. [검수 지침](../TRANSLATION_GUIDE.md), [NPC 말투](NPC_STYLE.md), [현재 번역 결정](TRANSLATION_DECISIONS.md), 용어집을 먼저 확인한다.

## 보고서 머리말

```text
기준: 저장소 커밋 / 전달받은 CSV 파일별 SHA256
검수일:
읽은 지침의 버전:
대상 파일과 검수한 레코드 범위:
미검수 범위:
사용한 원문·공식 자료·화면 근거:
실행한 검증 / 실행하지 못한 검증:
```

“전수 검수”라고 쓸 때는 실제 읽은 범위와 누락·중단 범위를 적는다. 도구로 후보만 검색한 범위를 의미 검수 완료로 계산하지 않는다.

## 항목별 기록

```text
ID:
구분: 오류 확인 / 문맥·폭 확인 필요 / 선택적 윤문
파일:
식별: CSV 레코드 번호(헤더 제외), Offset·Hash 또는 해당 형식의 키
일본어 원문:
현재 번역:
수정 제안:
실제 사용처·화자·상대·연결 문장:
오류 근거와 참고한 확정 결정:
조사·폭·줄 수·플레이스홀더 영향:
확인하지 못한 점:
```

셀 안 줄바꿈은 코드 블록이나 `\n`으로 보존한다. `st*`는 블록과 NPC ID를 함께, 서버 CSV는 빈 Key 대신 원문을 적는다. 퀴즈는 질문·보기 전체와 실제 정답 위치를 제시한다. 같은 Hash의 다른 행을 같은 문장으로 간주하지 않는다.

## 수정자의 처리 기록

| ID | 판정 | 근거·실제 변경 | 검증 결과 | 소스 커밋 |
|---|---|---|---|---|
| | 반영 / 기각 / 확인·판단 필요 | | 미실행은 미확인으로 기재 | |

보고서의 현재 번역이 이미 바뀌었다면 최신 파일로 다시 판단한다. 검증 후 커밋하고, 배포·추가 검증 결과와 서버 반영 대기는 별도로 기록한다. 다음 검수에는 최신 CSV와 처리 기록을 함께 전달한다.

## AI 검수 요청 예시

```text
AGENTS.md와 연결된 번역 지침·NPC 문서·현재 결정·용어집을 먼저 읽고,
제공한 CSV를 검수해 줘. CSV는 수정하지 말고 이 보고서 양식으로 제출해 줘.
원문과 실제 문맥을 근거로 오류 확인 / 확인 필요 / 선택적 윤문을 구분하고,
정상 문장의 취향 차이나 의도적인 퀴즈 오답을 오류로 단정하지 마.
판단에 필요한 자료가 없으면 미확인으로 남겨 줘.
실제 검수한 범위와 도구 검색만 한 범위를 구분해 적어 줘.
```

## AI 수정 요청 예시

```text
AGENTS.md와 연결된 문서를 읽고, 이 보고서를 최신 CSV와 독립적으로 대조해 줘.
근거가 확인된 오류만 최소 수정하고, 기존 정상 번역과 수정 목록 밖의 셀을 보존해 줘.
형식·표시·의미를 각각 검증하며 생성·후처리 뒤의 최종 결과도 다시 확인해 줘.
새 용어·캐릭터 말투처럼 판단이 필요한 항목은 원문·문맥·구체적인 대안을 보여 줘.
항목별 반영 / 기각 / 확인·판단 필요와 검증 결과를 기록하고,
커밋·배포는 AGENTS.md에 정해진 순서를 따라 줘.
```
