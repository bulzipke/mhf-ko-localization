# NPC 말투와 문맥

확인일: 2026-10-30. 아래는 확정 기록과 현재 CSV를 대조한 10명의 지침이다. 전체 NPC 목록이나 전체 대사의 검수 완료를 뜻하지 않는다.

**말투 규칙과 캐릭터 관찰을 구별한다.** 규칙은 명시된 화자·상대·장면에 적용한다. 특징은 원문을 이해하기 위한 참고이며, 그 특징에 맞추려고 대사를 새로 쓰지 않는다.

## 확정된 말투

| NPC | 적용할 말투·호칭 | 문맥에서 확인한 특징 |
|---|---|---|
| 클로에 / クロエ | 플레이어에게는 하게체·자네. 기존 혼용 부분만 교정 | 동료에게 존중받고 싶어 하는 이야기. 동료 상대 발화·취중·인용·독백은 별도 판단 |
| 플로라 / フローラ | `デス`도 자연스러운 요체. `@MYNAMEさん`은 `@MYNAME님` | 자신의 경험을 회상하고 정중하게 도움을 부탁함 |
| 키엘 / キエル | 반말·당신. 직함 `カシラ`는 두목 | 파로네 캐러밴 두목으로 대토벌 참여를 권유함. 하게체나 `~려무나`로 바꾸지 않음 |
| 오리올 / オリオール | `ッス` 계열은 `~임다/~슴다`. 인사는 `안녕하심까!` | 기구 정비를 맡으며 활기찬 후배 말투를 사용함 |
| 그레이엄 / グラハム | `お前さん`은 자네. 요청형은 하게체, 나머지 반말은 보존 | 나이 든 취급을 고민하며 프라우의 말투를 배우는 장면이 있음. 의도적인 흉내를 평소 말투로 고치지 않음 |
| 교관 / 教官 | `我輩`는 이 몸, `我輩達`는 우리. 플레이어에게 `貴様`는 너, `お前`는 자네 | 자네를 쓰는 명령·의문은 `~하게/~나/~는가`. 몬스터를 향한 네놈과 평서문은 별도 문맥 |
| 산나물 할아버지 / 山菜爺 계열 | 해라체. `ワシ`는 나/내, 2인칭은 너 | 노인다운 어휘·어조를 보존. `ハンターちゃん`은 헌터 짱, `ハンターさん`은 헌터님 |
| 타이조 / タイゾウ | 가희 스토리 `uc00_*`에서 반말·너 | 자신을 무적의 건랜스 사용자라고 부르는 열혈 화자. 다른 인물의 타이조 호칭과 구별 |
| 톳츠이 / トッツイ | 합쇼체를 기본으로 `~습니다냥/~습니까냥`, 요청은 `~세요냥` | 가희를 모시는 정중한 화자. 다른 인물에게 하는 발화는 상대와 장면을 확인 |
| 모빈 / モービン | 플레이어를 부르는 `さん`은 씨. 기존 반말·냥 어미 보존 | 조사 여행을 다녀오며 그림 등에 빗대어 멋을 부리는 표현을 사용함 |

결정 근거: 키엘은 2026-10-05, 오리올 인사는 2026-10-10, 그레이엄·교관·산나물 할아버지·타이조·톳츠이·모빈은 2026-10-12의 확정 기록을 따랐다. 클로에는 두 번째 외부 검수 때의 사용자 선택, 플로라는 2026-10-30의 최신 결정을 따른다. 특징 칸은 아래 대사와 같은 이야기의 문맥을 관찰한 요약이다.

## 원문과 현행 번역 예시

위치는 CSV 파일명과 식별값으로 찾는다. `st*`의 레코드 번호는 **헤더를 제외한 CSV 레코드 순번**이며, 텍스트 편집기의 물리적 줄 번호가 아니다. 예시는 해당 셀의 발췌다.

### 클로에

위치: `001_00_000.csv`, Offset `474`, Hash `6`

- 원문: `先に行っていてくれ。`
- 번역: `먼저 가 있어 주게.`

### 플로라

위치: `213_00_000.csv`, Offset `148`, Hash `2`

- 원문: `こんにちはデス！`
- 번역: `안녕하세요！`

`데스`를 음차하거나 `안녕하세요입니다`처럼 어미를 겹치지 않는다. 일반 `です`와 다른 등장인물의 말투까지 일괄 변환하지 않는다.

### 키엘

위치: `st260.csv`, 레코드 `2`, Offset `0`, Hash `180`

- 원문: `じゃあ、アンタ。頑張ってくれよ。`

## 호칭과 적용 범위

- 이름표의 정식 이름은 `hardcoded_names.csv`와 용어집을 대조한다. 대사에서 부르는 호칭은 화자·상대의 관계를 함께 본다.
- `さん`은 님을 기본으로 하되 모빈의 씨처럼 확정된 예외를 따른다. 사람이 부르는 `ネコさん`은 존댓말 화자에서 고양이님, 반말 화자에서 고양이씨다. 고유한 장비 이름에 이 규칙을 적용하지 않는다.
- `ちゃん`의 표기와 친족어 예외는 [현재 번역 결정](TRANSLATION_DECISIONS.md)을 따른다.
- 같은 파일 안에도 여러 화자와 인용·서술이 있다. 말투의 최빈값이나 이름이 등장한다는 사실만으로 화자를 정하지 않는다. 특히 그레이엄의 흉내, 클로에의 취중 발화처럼 원문에서 의도한 변화를 보존한다.

## 갱신 방법

새 NPC나 예외를 추가할 때는 **일본어 이름·실제 화자·상대·적용 장면·원문/번역 예시·CSV 식별값·결정 날짜와 근거**를 남긴다. 확정 전의 해석은 관찰로 표시한다. 말투가 바뀌면 기존 규칙을 갱신하고, 과거 결정을 현재 규칙과 함께 병렬로 남기지 않는다.
