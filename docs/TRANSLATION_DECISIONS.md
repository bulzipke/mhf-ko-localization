# 현재 번역 결정

확인일: 2026-11-01. 반복 검수에서 혼동하기 쉬운 현재 결정만 모았다. 개별 용어 전체는 [용어집.csv](../용어집.csv), 대사 말투는 [NPC 문서](NPC_STYLE.md), 폭과 조사 규칙은 [검수 지침](../TRANSLATION_GUIDE.md)을 따른다.

## 판단 근거

- 최신 사용자 확정 사항의 날짜와 적용 범위를 먼저 확인한다. 과거 보고서·옛 번역이 최신 결정을 덮어쓰지 않게 한다.
- 용어집은 한국어 값과 비고를 함께 읽고, 원문의 같은 대상·같은 사용처인지 확인한다. 분류나 출현 빈도만으로 뜻을 정하지 않는다.
- 공식 한국어판 자료도 일본어 원문과 역할이 일치해야 근거로 쓴다. 용어집·현행 CSV·기존 결정이 충돌하면 그 차이를 보고하고, 확인 없이 전역 치환하지 않는다.

문장부호의 물결표·말줄임표 규칙은 [검수 지침](../TRANSLATION_GUIDE.md)의 **표기·조사**에만 유지한다. 이름표·호칭·말투의 예외는 NPC 문서와 용어집 비고에 기록해 서로 다른 문서가 다른 규칙을 갖지 않게 한다.

새 결정을 기록할 때는 **대상 원문, 사용처, 최종 표기, 날짜·근거, 예외, 대체된 결정**을 적는다. 아직 승인되지 않은 제안은 이 표에 확정 사항으로 추가하지 않는다.
