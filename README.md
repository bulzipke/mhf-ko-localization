# Monster Hunter Frontier Korean Localization
본 프로젝트는 Erupe 서버에서 구동되는 `몬스터 헌터 프론티어(Monster Hunter Frontier)`를 한국어로 즐기기 위한 커뮤니티 기반 한글화 프로젝트입니다.

## 📌 소개
본 패치는 일본어판 텍스트 데이터를 기반으로 하며, 과거 한게임 서비스 당시의 번역 데이터도 참고하여 제작되었습니다. 유저들이 더 편안하게 게임을 즐길 수 있도록 텍스트, UI, 아이템 명칭 등을 한국어로 현지화하는 것을 목표로 합니다.

번역 개선이나 오타 수정을 제안할 때는 아래 자료를 먼저 확인해 주세요.

공개 저장소의 번역 CSV는 `번역중/`에 있습니다. 관리자 작업 사본에서는 `작업중/`을 사용합니다. `원본/`·`참고/`는 기준 자료로 보존하며, 번역을 완료한 행도 삭제하지 않습니다.

CSV는 셀 안에 줄바꿈이 있으므로 CSV 파서로 읽고, 번역 열만 최소 수정해 주세요. 저장 도구가 인코딩·줄바꿈·따옴표를 바꾸지 않았는지 확인해야 합니다. 공식 한국어판 자료도 같은 일본어·같은 사용처인지 대조하고, 최신 확정 결정과 문맥을 함께 확인합니다.

수정 제안은 저장소를 Fork한 뒤 Pull Request로 보내 주세요. 검수한 기준 버전, 변경 전후 문구, 수정 근거와 검증 결과를 함께 적어 주시면 검토에 도움이 됩니다. 실행하지 못한 게임 화면·빌드 검증은 미확인으로 표시해 주세요.
